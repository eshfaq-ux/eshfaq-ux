# Ashfaq Nabi - Premium Gen-Z Coder Profile

A modern, animated portfolio built with Next.js, TypeScript, and Framer Motion.

## 🚀 Features

- **Modern Typography**: Bold, editorial-style headlines with gradient text
- **Animated Interactions**: Smooth animations and transitions using Framer Motion
- **Glassmorphism Design**: Premium glassmorphic UI elements with blur effects
- **Cyberpunk Vibes**: Neon gradients and glowing effects
- **Responsive Design**: Fully responsive across all devices
- **Dark Mode**: Optimized for dark mode with beautiful color palette
- **Performance**: Optimized for fast loading and smooth animations

## 📚 Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🎨 Color Palette

- **Primary**: `#00D9FF` (Cyan)
- **Secondary**: `#FF006E` (Pink)
- **Accent**: `#8000FF` (Purple)
- **Dark**: `#0a0e27`
- **Darker**: `#050812`

## 🛠️ Installation

```bash
cd profile-app
npm install
# or
yarn install
```

## 🚀 Getting Started

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

```
profile-app/
├── app/
│   ├── layout.tsx        # Root layout
│   ├── page.tsx          # Home page
│   └── globals.css       # Global styles
├── components/
│   ├── Navigation.tsx    # Navigation bar
│   ├── Hero.tsx          # Hero section
│   ├── About.tsx         # About section
│   ├── Skills.tsx        # Skills showcase
│   ├── Projects.tsx      # Featured projects
│   ├── Contact.tsx       # Contact section
│   └── FloatingElements.tsx # Background effects
├── tailwind.config.ts    # Tailwind config
├── tsconfig.json         # TypeScript config
└── package.json          # Dependencies
```

## 🎯 Key Components

### Hero Section
Features animated headline, tagline, CTA buttons, and social links with smooth entrance animations.

### About Section
Introduction with core strengths displayed in an interactive glassmorphic card.

### Skills Section
Tech stack organized by category with hover animations.

### Projects Section
Featured projects showcase with GitHub links and technology tags.

### Contact Section
Multiple ways to get in touch with animated cards and CTA.

## ✨ Customization

- Update content in component files
- Modify colors in `tailwind.config.ts`
- Adjust animations in Framer Motion variants
- Add new projects in `Projects.tsx`
